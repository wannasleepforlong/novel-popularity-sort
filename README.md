# novel-popularity-sort
Script to allow sorting by popularity


Pixv doesn't allow sorting by popularity so this script can do that function.

Installation
- Install the Tampermonkey extension if you don’t have it.
- Open the Tampermonkey dashboard → Create a new script, paste the file’s contents, save. (Or open the .user.js file directly in your browser and Tampermonkey will offer a one-click install.)
- Reload the Pixiv page you linked.
